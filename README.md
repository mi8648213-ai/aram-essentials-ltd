# Aram Essentials Ltd — Content Area

This first ZIP is a static, GitHub/Hostinger-ready website.

## Gallery
Put new images in:
`assets/images/`

Then add their filenames to `galleryFiles` in `script.js`.

## Videos
Put MP4 files in:
`assets/videos/`

Then add their filenames to `videoFiles` in `script.js`.

## Audio
No audio files are included, as requested. The website is prepared for a future audio section.

## Important
The service request form currently creates a reference number in the browser only. A real production system needs a backend/database or an external form service to receive submissions and uploaded documents securely.

The `admin/` folder is reserved for the future no-code content management system.
